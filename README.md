# 🤖 HASA MART BOT

Official WhatsApp Cloud API Bot for HASA Online Mart.

## Features

- WhatsApp Cloud API
- Automatic Welcome Messages
- Sinhala and English Replies
- Product Inquiries
- Price Inquiries
- Order Assistance
- Delivery Information
- Customer Support
- Render Hosting Support

## Requirements

- Node.js 20+
- Meta WhatsApp Cloud API
- WhatsApp Phone Number ID
- Permanent Access Token
- Webhook Verification Token

## Installation

```bash
npm install
```

## Environment Variables

Configure these variables in your hosting dashboard:

- WHATSAPP_TOKEN
- PHONE_NUMBER_ID
- VERIFY_TOKEN
- GRAPH_API_VERSION

## Start

```bash
npm start
```
